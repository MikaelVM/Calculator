# Project - Create a calculator
This project is a simple calculator application built using Python, demonstrating basic programming concepts and CLI design.

I was never meant to be full-fledged project, but rather something the course participants at the Specialisterne Academy
could work on in the background, whenever other tasks where completed early in the first week of the academy.

## Exercise Goal
Implement an calculator application that can perform basic arithmetic operations such as addition, subtraction, 
multiplication, and division.

# See the Solution in Action
1. Install the required dependencies from the `requirements.txt` file.
2. Use the command line interface (CLI) to perform calculations. For example: `python main.py calculate 2-32+50*2-20/2`
